# E-Poch intro video

An 88-second, 1920×1080 intro, built in Remotion and timed to the Gemini TTS voiceover.

| | |
|---|---|
| `script.md` | The voiceover script and the TTS settings it was recorded with |
| `epoch-intro/` | The Remotion project. `npm run dev` opens Studio |
| `music.py` | Synthesizes the music bed (`epoch-intro/public/audio/music.wav`), beat-locked to the voice and ducked under it |
| `capture/` | How the real app footage was recorded (Playwright + Chrome screencast, with a visible cursor) |

## Preview and render

```sh
cd epoch-intro
npm i
npm run dev                                   # Studio: EpochIntro, plus each scene under Scenes/
npx remotion render EpochIntro out/epoch-intro.mp4 --crf=18
```

## How it is timed

`epoch-intro/src/timeline.ts` holds every spoken word's start time, measured from the voiceover with
faster-whisper word timestamps (`capture/voice-words.json`). Scenes, captions, camera moves and sound
effects (`src/Sfx.tsx`) are all keyed to those times. If the voiceover is re-recorded, re-run
`capture/transcribe.py`, update `W` in `timeline.ts`, and re-run `music.py`.

## Footage

Every screen is the real application, recorded against a throwaway `epoch_video` database filled with
the demo seed (fictional patients). It is never the clinic database.

1. `capture/reseed.sh` recreates `epoch_video` and loads `prisma/seed-demo.ts`.
2. Start the API on :3100 with `DATABASE_URL` pointing at `epoch_video`, and the frontend on :5180
   with `VITE_API_URL=http://localhost:3100`.
3. In a folder with `playwright-core` installed: `node c_login.mjs`, `node clips.mjs`, `node stills.mjs`.
   The output goes to `clips/` and `stills/`, which you copy into `epoch-intro/public/`.

## Audio

- The voice is normalized to -16 LUFS (`public/audio/voice.wav`).
- The music is original, generated by `music.py` (no licensing).
- Sound effects are Kenney CC0 packs (via soundcn) and Remotion's free SFX in `public/sfx/`.
